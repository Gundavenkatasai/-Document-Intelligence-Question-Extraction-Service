# 7. DOCUMENT PROCESSING

For every document:

1. Create a database record.
2. Set status to `PENDING`.
3. Queue asynchronous processing.
4. Worker changes status to `PROCESSING`.
5. Determine document type.
6. Determine page count.
7. Process each page.
8. Preserve page numbering.
9. Extract native text when available.
10. Use OCR when native extraction is insufficient.
11. Preprocess poor-quality images when required.
12. Normalize extracted content.
13. Identify question boundaries.
14. Resolve questions spanning pages.
15. Extract structured question data.
16. Detect answer-key sections.
17. Associate answers with questions.
18. Calculate confidence.
19. Create review items for uncertain results.
20. Persist results.
21. Set document status to `COMPLETED`.

If processing fails:

```text
PROCESSING → FAILED
```

and store a useful sanitized error message.

Never leave a document indefinitely stuck in `PROCESSING`.

# 12. MULTI-PAGE QUESTIONS

This is a critical requirement.

A question may begin on page N and continue on page N+1.

Do not create two separate questions simply because a page boundary occurs.

```text

17. Which of the following...
A. ...
B. ...

Page 5:
C. ...
D. ...
```

The result should be one question:

```json

  "source_pages": [4, 5],
  "options": [...]
}
```

The implementation must preserve all relevant source pages.

# 18. CONFIDENCE SYSTEM

Implement a transparent confidence mechanism.

Do not make confidence a meaningless random number.

Confidence should consider signals such as:

* question structure completeness
* presence/quality of question text
* option completeness
* OCR quality
* numbering consistency
* page-boundary consistency
* answer-key matching confidence
* AI structured-output validity
* extraction warnings

Create a documented scoring function.

Example conceptual model:

```text
overall confidence =
    text quality
  + structural completeness
  + option consistency
  + page continuity
  + answer matching confidence
  - extraction penalties
```

Normalize the result to:

```text
0.0 → 1.0
```

Use a configurable review threshold.

Default:

```text
confidence < 0.75
→ PENDING_REVIEW
```

The threshold must be configurable rather than hard-coded throughout the codebase.

Document exactly how the score is calculated.
